# Python Data Analysis Skills Lab

A self-guided, practical data analysis project using a fictional online retailer.

## Setup
1. Install Python 3.10+.
2. Open this folder in VS Code.
3. Create/activate a virtual environment if you want one.
4. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Run the starter program:

   ```bash
   python main.py
   ```

6. Run the tests after implementing functions:

   ```bash
   python -m pytest
   ```

## Project structure
- `data/` — four related CSV files
- `src/analysis.py` — functions for you to implement
- `main.py` — loads the data and runs your analysis
- `tests/` — basic automated checks
- `CHALLENGES.md` — your assignment list

## Rules
- Try each challenge before looking anything up.
- You may use Python, pandas, NumPy, and matplotlib.
- Do not manually edit the CSV files to hide data-quality issues.
- Write reusable functions instead of putting everything in one long script.
- Keep notes about assumptions you make while cleaning data.
- The dataset is synthetic; it does not describe real people or businesses.

## Suggested workflow
Start with Challenge 1. Implement the corresponding function(s), run the tests, inspect the output, and then move to the next challenge. The final project combines the skills from all sections.
